# Reglas de calidad de modelos e informes

| Fichero | Herramienta | Qué contiene |
|---|---|---|
| `bpa/reglas-proyecto.json` | Best Practice Analyzer (Tabular Editor 2) | Reglas propias del framework. Se suman a las reglas de Microsoft, que el script descarga fijadas por commit y huella |
| `fab-inspector/reglas.json` | Fab Inspector | Opcional. Si no existe se usan las reglas base de Fab Inspector. Para personalizarlas, copia las base aquí y edítalas |

Cómo y cuándo se ejecutan: README principal, sección **Calidad y linters**.
